# Local acceptance results — 1 October 2026

These are historical results from the synthetic local acceptance runs described in [verification](../verification.md), not results from GitHub Actions or live Firestore.

The EDN suite summaries, storage/database test summaries, and recovery JSON results are copied from the original runs. The HTTP summary retains only checks, success, export size, and export checksum; local profile/file identifiers and the workspace URL were omitted. The rendered PNG is the synthetic 320 × 180 rectangle.

The build manifest identifies the engine image used for the final acceptance suite and hashes its inputs. Public packaging later added license copies and OCI labels to the Dockerfile; the C engine and Python supervisor remain the same as the hashed source. Raw application, browser, protocol, and build logs are kept outside the public repository.
